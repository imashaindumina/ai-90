# ai-90

A structured 90-day program to become a working AI engineer — from Python
fundamentals to deployed RAG systems, agents and production applications.

Building in public. Each day's work is committed here.

## Roadmap

| Days | Focus |
|------|-------|
| 01–07 | Python foundations, Git, environment |
| 08–14 | LLM APIs, prompting, structured output, tool calling |
| 15–21 | FastAPI, Docker, deployment |
| 22–28 | Data: pandas, SQL, scraping, visualisation |
| 29–42 | Embeddings, vector search, RAG, evaluation |
| 43–56 | Agents, workflow automation, chatbots |
| 57–63 | Classical ML, model serving |
| 64–90 | Specialisation, portfolio, first clients |

## Stack

Python 3.12 · FastAPI · Docker · pandas · scikit-learn · LLM APIs · vector databases

## Setup

```bash
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
